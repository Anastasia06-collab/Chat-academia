## 🌟 О проекте

Современный адаптивный веб-сайт для группы компаний **«CATRINE & AVALON-K»**, выполненный в эстетике «тихой роскоши» и минимализма. Разработан на **чистом стеке**: без тяжелых библиотек, фреймворков и сборщиков.

- **Стек:** HTML5 (семантика) + CSS3 (Custom Properties, Flexbox, Grid) + Vanilla JS (ES6+).
- **Дизайн-система:** Тёплый молочный беж (`#FAF8F5`), глубокий графитовый чёрный (`#121212`) и благородное шампань-золото (`#B8976C`), с акцентным красным (`#C94A4A`) для корпоративного крыла AVALON-K.
- **Типографика:** `Playfair Display` (элегантные заголовки с засечками) + `Plus Jakarta Sans` (чистый технологичный гротеск).
- **Язык интерфейса:** Русский (`lang="ru"`).

## 🚀 Быстрый запуск локально

### Способ 1: Открытие напрямую в браузере
Просто дважды кликните по файлу `index.html` или перетащите его в окно любого современного браузера (Google Chrome, Safari, Edge, Firefox).

### Способ 2: Запуск через локальный HTTP-сервер
Для идеальной работы всех путей и шрифтов рекомендуется использовать локальный сервер:

- **С помощью Python 3:**
  ```bash
  python -m http.server 8000
  ```
  Затем откройте в браузере: `http://localhost:8000`

- **С помощью VS Code Live Server:**
  Установите расширение *Live Server* и нажмите кнопку `Go Live` в правом нижнем углу редактора.

- **С помощью Node.js (npx serve):**
  ```bash
  npx serve .
  ```

## 🌐 Выгрузка на GitHub Pages (пошаговая инструкция)

1. **Создайте репозиторий на GitHub:**
   - Перейдите на [github.com/new](https://github.com/new).
   - Введите имя репозитория, например `catrine-avalon`.
   - Оставьте репозиторий публичным (**Public**).

2. **Инициализируйте локальный Git-репозиторий и отправьте файлы:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: CATRINE & AVALON-K landing page"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_АККАУНТ>/catrine-avalon.git
   git push -u origin main
   ```

3. **Включите GitHub Pages:**
   - В созданном репозитории перейдите во вкладку **Settings** (Настройки).
   - В боковом меню слева выберите раздел **Pages**.
   - В блоке **Build and deployment** установите:
     - **Source:** `Deploy from a branch`
     - **Branch:** `main` / каталог `/ (root)`
   - Нажмите кнопку **Save**.

4. **Получите ссылку на сайт:**
   Через 1–2 минуты страница будет опубликована по адресу:  
   `https://<ВАШ_АККАУНТ>.github.io/catrine-avalon/`

## ⚡ Реализованный функционал

1. **Шапка сайта (Header):**
   - Умное уменьшение высоты (80px → 70px) и увеличение плотности подложки при скролле вниз.
   - Плавное золотое подчеркивание ссылок меню при наведении.
   - Кнопка вызова обратной связи со скроллом и автофокусом.
   - Адаптивное меню-шторка для мобильных устройств с затемнением и блокировкой скролла страницы.

2. **Hero-секция:**
   - Медленный эффект кинематографичного зума интерьера.
   - Каскадная анимация появления текста и метрик.
   - Интерактивный индикатор скролла с анимированным колесиком мыши.

3. **4 Направления фабрики:**
   - Сетка карточек с зумом изображений, золотыми маркерами преимуществ и счетчиками объектов.
   - Кнопки заказа автоматически переключают выпадающий список в форме заявки на выбранное направление и прокручивают к контактам.

4. **Интерактивное портфолио с лайтбоксом:**
   - Мгновенная фильтрация по категориям (B2B, частные интерьеры, модули, текстиль) с плавным масштабированием.
   - Полноэкранный модальный просмотр работ с затемнением фона, описанием и закрытием по клавише `Esc` или клику мимо окна.

5. **20-летняя хроника (Timeline):**
   - Выделенные тёмные контрастные карточки для ключевых исторических вех (основание AVALON-K, открытие фабрики 6000 м², EXPO, флагманский салон 2026).

6. **Форма обратной связи:**
   - Автоматическая маска ввода номера телефона `+7 (XXX) XXX-XX-XX`.
   - Живая клиентская валидация обязательных полей с подсветкой ошибок.
   - Имитация отправки (700 мс) с отображением карточки успешного подтверждения и кнопкой для повторной отправки.

7. **Плавающие виджеты:**
   - Пульсирующая кнопка WhatsApp с тултипом и готовым предзаполненным сообщением консультанту.
   - Кнопка быстрой плавной прокрутки наверх (появляется после 450px скролла).

8. **Интеллектуальный AI-консультант «Катрин»:**
   - Встроенный интерактивный AI-помощник фабрики в фирменной эстетике и Tone of Voice бренда.
   - Обучен на регламенте «Путь заказа» (10 этапов), карте CJM персоны Айгуль и концепции доверия.
   - Отвечает на вопросы о гарантиях, сроках, этапах замера и производства, выборе оттенков и шпона, немецкой фурнитуре Hettich и направлениях фабрики.
   - Содержит быстрые подсказки (chips), индикатор набора сообщения и быстрый бесшовный переход к форме расчета и WhatsApp.
